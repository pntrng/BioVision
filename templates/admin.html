🔐 Admin Token

Token được lưu trong localStorage. Cần token để lưu dữ liệu.

Quy trình:

  1. Nhập Admin Token (từ Render environment variables)
  2. Điền thông tin khối lớp, chương, mô hình
  3. Bật Chọn điểm → click lên mô hình để lấy vị trí
  4. Xoay đến góc muốn → bấm Lấy góc camera
  5. Điền nhãn điểm, mô tả, link (nếu có) → Thêm mới
  6. Lưu lên Server để lưu

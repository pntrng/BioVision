# BioVision static read-only export

Bản này là phiên bản tĩnh/read-only của BioVision.

- index.html: giao diện học sinh
- data.json: dữ liệu public lấy từ Render API
- static/: CSS, hình ảnh và assets
- mindmap_order.json: thứ tự cây kiến thức nếu có
- pi/data: bản sao dữ liệu để dự phòng tương thích đường dẫn cũ

Các chức năng admin, đăng nhập, lưu/sửa dữ liệu không hoạt động trong bản static.
